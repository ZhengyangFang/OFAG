# Public release scope

This repository distributes part of the OFAG code and documentation for peer review. The authors plan to release the complete system and related author-created documentation after manuscript acceptance. The installed wheel contains the public runtime code and generic agent guidance.

Research case data, case scripts, figure notebooks and outputs, run records, audit ledgers, development histories, and the full research lesson corpus are retained separately during manuscript review. They are not part of this repository or its source and wheel archives. The public synthetic lesson is an interface example and is not presented as a research result.

The public tests use synthetic inputs to check the distributed runtime. Tests tied to the unpublished cases remain with the complete local project.

Users can import their own datasets and run the framework. Reproducing the manuscript's field cases requires case materials released through a separate route after the authors complete the review and rights checks.
